Paisa

AI CFO & financial operating system · July 2026 — present

The language model never touches arithmetic. A tested engine computes every figure — expenses, UPI, SIPs, loans, investments, tax — and the model's only job is to explain what the engine returned. Above it sit four agents with separate remits for accounting, tax, investing and planning, and a router that decides which one should answer. Bank accounts connect through secure connectors, so the numbers being explained are real ones.

~/nutriscan-ai in production

NutriScan AI

AI health agent — clinical reasoning · 2026

An AI health agent that reasons over symptoms, lab results and clinical history. Five specialists — doctor, labs, fitness, nutrition and coach — sit behind a supervisor that routes each question to whichever one should own it, and each specialist only sees the slice of the patient record it needs. Underneath the chat is the part that matters: a deterministic triage engine of forty clinical rules that runs before the model reasons, fails closed on error, and can end the turn outright. A model may raise suspicion; nothing can lower a rule-derived verdict. Insights carry their own certainty, derived from sample size rather than asserted, and any number the agent quotes is computed in tested code. 156 tests.

built withtypescript · next.js · anthropic & openai apis · python · fastapi · pytorch · postgresql · react native · docker
